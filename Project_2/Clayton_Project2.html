yearly = df_filt_DMV.groupby(["year", "state_abb"])["unemployment_rate"].mean().unstack() # average unemployment rate for each year and state, with one column per state

plt.figure(figsize=(9, 5))   # creating the figure
plt.plot(yearly.index, yearly["DC"], marker="o", label="DC")   # DC line
plt.plot(yearly.index, yearly["MD"], marker="o", label="MD")   # Maryland line
plt.plot(yearly.index, yearly["VA"], marker="o", label="VA")   # Virginia line
plt.title("Average Unemployment Rate by State in DMV (2009–2024)")  # title
plt.xlabel("Year") # x-axis
plt.ylabel("Unemployment rate") # y-axis 
plt.legend(title="State")   # key
plt.show() # display the figure

The line graph portrays a detailed account of the average unemployment rates per year across the DMV from 2009 to 2024. Our research question focuses on the relationship between unemployment rate and crime rate across the DMV, so this graph provides insight into how unemployment rate has changed overtime for each respective state. We can see that that all the states follow the same pattern that may be influenced by national or global events that impact the whole country. Yet, it is noticeable that D.C. always has a higher unemployment rate compared Maryland and Virginia. This may impact the results of our cross DMV tests when we begin testing the relationship between unemployment rate and crime rate across the region.

va = larceny[larceny["state_abb"] == "VA"]   # Virginia rows only
plt.figure(figsize=(9, 5))   # creating the figure

plt.scatter(dc["unemployment_rate"], dc["count"], color="blue", label="DC")     # DC 
plt.scatter(md["unemployment_rate"], md["count"], color="orange", label="MD")   # Maryland 
plt.scatter(va["unemployment_rate"], va["count"], color="green", label="VA")    # Virginia 

plt.title("Unemployment Rate vs. Larceny-Theft Count")   # title
plt.xlabel("Unemployment rate")  # x-axis 
plt.ylabel("Larceny-theft count") # y-axis 
plt.legend(title="State") # key
plt.show() # display the figure

I chose to create a scatterplot based on the things I found interesting in section 1 of Project 2. I know the goal of our project was to create a scatterplot or regression that ran unemployment rate against crime rate across the DMV. Yet, becuase I saw that larceny theft was by far the most occuring crime, I wanted to increase the scope and run the test focusing on the crime category of larceny theft rather than all crime types. As such, we are able to see the relationship and see it color coded by state rather than making it all the same color. For Maryland and Virginia, we can state that there is a positive correlation between unemployment rate and larceny theft count. Meaning that as the unemployment rate goes up, the count of larceny thefts increases as well. Yet, this relationship is not held in D.C. As the unemployment rate increase in D.C., the count of larceny theft count remains stagnant. So overall, I have been able to learn that D.C. is always the outlier and may recquire its own framework of study rather than being included within a DMV regional analysis.
